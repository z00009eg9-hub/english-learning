# Benny 英文助理

小型圓頭入口：桌機 56px、手機 48px。收合時仍緩慢左右轉頭，不主動發聲。
滑鼠或單指左右拖曳可旋轉（最多約 34°），放開後緩慢回正；拖曳不開啟面板，也不觸發網站翻篇手勢。
低動態偏好關閉自動動畫，仍可手動旋轉；睡眠、隱藏與背景分頁停止動畫。
支援 32px 迷你模式，偏好記錄於本機 `b2lab_assistant_mini`。
隱藏偏好只記錄在本機 `b2lab_assistant_hidden`，可由「顯示助理」還原。
面板頂端「縮小」只收合面板；「縮成迷你」會同時縮小入口。

## 功能與界線

- 單字查詢：本課優先，再查全站字庫、課本片語與實景字彙；支援詞形還原、部分符合與選取帶入，顯示已有的音標、詞性、中文、例句、來源與喇叭。查無資料時不生成解釋。
- 帶我跟讀：教材句子或使用者選取的英文，沿用網站 `say / ttsStop`，支援喇叭、正常及慢速播放與狀態提示。
- 單字小測：使用本課單字的字義組成選項，僅在面板中顯示結果，不寫入正式測驗成績。
- 句子重組：本課原句打亂詞序，支援逐詞退回、重排、檢查、標示詞序差異、答案與朗讀。僅依教材原句核對，不提供自由造句評分。
- 新文章：頭像正上方的小對話框附尾巴與「看看／×」，按鈕可開啟當日新文章。依首次加入網站版本的時間判斷，因此沒有日期或回填舊日期的文章也能辨識。預排文章仍等到指定日期才提示。
- 以每位使用者、當地日期與文章 ID 記錄已提醒批次（`b2lab_assistant_news_seen_<profile>`）；同一批重新整理不重複，同日下一批重新進站仍提醒。修正舊文不視為新文章。睡眠、隱藏與背景分頁不彈提示，也不申請通知權限。
- 清單頁也能查全站單字；跟讀與練習則提示先開啟教材。

## 睡眠

從最後一次操作助理起算五分鐘，自動收合、閉眼並停止動畫。
網站正在播放語音時延後睡眠，每 15 秒重查；切到背景時停止助理自己的語音與動畫。
點頭像一次即可喚醒；同一課的查詢與重組進度保留在面板，不上傳。
換課時重新準備練習，查詢結果仍可保留。

沒有新增 AI API、語音辨識、錄音、雲端寫入或任何訂閱服務。
朗讀沿用既有音檔及裝置語音；網站原本的託管與音檔流量政策仍適用。

## 整合

`index.html` 的 `window.b2Assistant` 提供 `context / search / news(releases) / openArticle / speak / stop / busy`。
`context()` 僅讀當前教材，排除作業訂正、測驗與口語速記；多句段落拆句後不冒用整段中譯。
介面使用 Shadow DOM 隔離樣式。首屏之後、頭像可見時載入 `head.js` 與既有 MIT Three.js，
WebGL 或載入失敗時保留 CSS 圓形頭像與完整教學操作。
隱藏分頁與關閉面板會停止助理發起的語音，離頁會釋放 3D 資源。

驗證時請關閉 Firestore 連線或使用隔離測試環境，避免測試進度寫入使用者資料。

## 新文章清單

`node b2lab/tools/build-article-releases.js` 依完整 Git 歷史產生 `article-releases.json`，不要手改 JSON。
閱讀、每日、A2 以文章 ID 辨識；舊課堂筆記依標題追溯，再對應目前的列表 ID。
時間採首次加入版本的 commit 時間（main 一般由 CI 立即部署），不是後續編輯時間。
CI 使用完整 checkout，每次部署前自動重建；本機新增教材後也可執行此指令取得最新清單。
清單以同源請求載入並加入離線快取；無法取得時僅退回教材本身的日期，不推測未標日期文章的發布日。
